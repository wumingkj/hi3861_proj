## 存储限制

### 容量限制
- 最大KV对数量：50个
- 最大键长度：32字节
- 最大值长度：128字节

### 性能考虑
- Flash写入次数有限
- 合理设置自动保存间隔
- 避免频繁的小数据写入

## 调试支持

### 状态监控
```c
uint32_t used, free, total;
nv_get_status(&used, &free, &total);
log_i("NV", "Storage: %lu/%lu bytes used", used, total);
```

### 键列表查看
```c
char keys[10][NV_MAX_KEY_LEN];
uint16_t count;
nv_get_keys(keys, 10, &count);
for (int i = 0; i < count; i++) {
    log_d("NV", "Key[%d]: %s", i, keys[i]);
}
```
