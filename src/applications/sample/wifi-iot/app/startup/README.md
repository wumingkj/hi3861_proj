# 启动模块

## 模块概述

启动模块是项目的核心入口，负责系统初始化和各功能模块的协调工作。该模块实现了基于CMSIS-RTOS2的多任务架构，确保系统稳定运行。

## 技术更新

### 存储系统升级
- ✅ **从自定义NV模块升级到标准KV存储系统**
- ✅ 使用Hi3861标准LiteOS KV存储，解决兼容性问题
- ✅ 实现断电保存验证功能
- ✅ 支持自动配置初始化

## 系统架构

### 任务结构

```
系统入口 (Main_Entry) 
├── KV存储初始化 
├── 断电保存验证 
├── 传感器初始化 
├── 蜂鸣器初始化 
└── 多任务创建 
├── 网络任务 (NetworkTask) 
├── PHP API任务 (PHP_API_Task) 
└── 主任务 (Main_Task) 
├── 传感器数据采集 (每2秒) 
├── LED状态控制 (每100毫秒) 
├── 蜂鸣器状态更新 (每5毫秒) 
└── 系统监控和错误处理
```
